# Luntian Kitchen

Restaurant table reservation site. React + Tailwind CSS (front-end only).

## Run
    npm install
    npm run dev

## Structure
- `src/models`: OOP classes (Table, Reservation)
- `src/data`: table data (Table objects) and all UI text (content.js)
- `src/context`: app state (favorites, reservations)
- `src/pages`: Home, Tables, TableDetails, Favorites, Reserve, MyReservations

## Palette

Fonts: Bricolage Grotesque (headings), Figtree (body)
